# data/ (not in git)

Everything in here is either generated by the code or downloaded. Only this README is tracked.

| Folder | Contents | How to get it |
|---|---|---|
| `synthetic/` | BoolODE benchmark networks `BF_rep*.h5ad`, `TF_rep*`, `CBF_rep*`, `HSC_rep*` (~1 MB each) | `bash scripts/run_all.sh` (simulates them), or copy from a collaborator |
| `tree/` | random nested-tree networks `T08_d3_n2.h5ad` = p 0.8, depth 3, network 2 | `bash experiments/tree_depth/run_tree_all.sh` |
| `real/` | prepared real datasets: `nestorowa16.h5ad`, `larry_invitro.h5ad` | the prepare scripts below |
| `raw/nestorowa/` | `GSE81682_HTSeq_counts.txt.gz` (GEO GSE81682), `all_cell_types.txt`, `cluster_ids.txt` (from the Nestorowa et al. 2016 supplement / Göttgens lab site), `MRK_ENSEMBL.rpt` (MGI, informatics.jax.org/downloads/reports) | download, then `python experiments/real_data/nestorowa_prepare.py` |
| `raw/LARRY/` | `stateFate_inVitro_{normed_counts.mtx, gene_names.txt, metadata.txt, clone_matrix.mtx}.gz` (Weinreb et al. 2020, GEO GSE140802, also github.com/AllonKleinLab/paper-data) | download, then `python experiments/real_data/larry_prepare.py` |
| `raw/suberites_domuncula/` | `suberites_domuncula_cytotrace_SUB4.h5ad` (sponge atlas, CytoTRACE pseudotime), `SUB4_TF_gene_ids.csv` (TF annotation) | lab-internal; ask the project lead |

Paul15 (diagnostic only, not in the paper) is read from
`archive/2026-02_group_exploration/trajectory_analysis_output/paul15_processed.h5ad`.
